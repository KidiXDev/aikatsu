# Give softer video a little help

Anime4K is optional video processing for sharper lines and cleaner-looking upscaling. It works through the player on desktop and Android. It doesn't change the source file or create a higher-bitrate stream.

## Turn it on

Open **Settings > Sharpen video (Anime4K)**, or **Settings > Watch** on desktop, where each preset shows a short description. Select a preset. If the shaders aren't installed yet, they download the first time a preset is used; choose **Download** (**Download now** on desktop) to get them ahead of time. You can also change the preset from the player's Anime4K menu.

The standard shader pack is downloaded once. The Experimental preset needs additional shaders, which the app fetches when needed.

## Pick a preset

| Preset | A good place to use it |
| --- | --- |
| Off | Original playback, or when you want to save power |
| Standard | A starting point for most anime |
| Soft | Video that already looks fairly clean |
| Denoise | Grainy or blocky video, with a capable GPU |
| Light | Weaker graphics hardware or a phone running warm |
| Maximum | Strong cleanup on a powerful GPU |
| Experimental | Very low-quality video, with a big performance cost |
| Extra sharp | Crisper lines, though faint halos can appear |
| Extra soft | 720p video with jagged edges |
| Denoise + sharpen | A starting point for 480p video |

There isn't one best setting for every show. Try a scene with faces, line work, and motion before deciding.

## If playback gets choppy

Switch to Light or Off. Shader processing can use a lot of GPU power, especially on phones. If the video becomes smooth with Anime4K off, the source connection probably wasn't the problem.

You need an internet connection for the shader download. Once the files are installed, applying them doesn't need another download for each episode.
