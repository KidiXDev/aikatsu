# Anime4K video sharpening

Anime4K sharpens video during playback on desktop and Android. It can improve lines when video is enlarged, without changing the source file or stream bitrate.

## Enable Anime4K

Open **Settings > Sharpen video (Anime4K)**, or **Settings > Watch** on desktop, and choose a preset. Desktop shows a short description of each one. The shaders download on first use. To download them ahead of time, choose **Download** (**Download now** on desktop). You can also switch presets in the player's Anime4K menu.

The standard shader pack downloads once. Experimental downloads extra shaders when needed.

## Presets

| Preset | Suggested use |
| --- | --- |
| Off | Original playback, or when you want to save power |
| Standard | A starting point for most anime |
| Soft | Video that already looks fairly clean |
| Denoise | Grainy or blocky video, with a capable GPU |
| Light | Weaker graphics hardware or a phone running warm |
| Maximum | Strong cleanup on a powerful GPU |
| Experimental | Very low-quality video, with a big performance cost |
| Extra sharp | Crisper lines, though faint halos can appear |
| Extra soft | 720p video with jagged edges |
| Denoise + sharpen | A starting point for 480p video |

Try a scene with faces, line work, and motion to find a preset that suits the show.

## Playback performance

If playback stutters, switch to Light or Off. Shader processing can use a lot of GPU power, especially on phones. Smooth playback with Anime4K off usually points to shader performance as the cause.

You need an internet connection to download shaders. The player shows download progress, then the active preset's name. If the download fails, sharpening stays off for that playback session and tries again next time. Installed shaders work across episodes without another download.
